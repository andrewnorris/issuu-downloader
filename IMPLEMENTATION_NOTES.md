## Changes

The strict pipeline is in archival.py. It validates every metadata-listed page,
checks paywall flags, applies bounded transient retries and Retry-After, and uses
atomic cache/manifests/output. It hashes SVGs/PDFs, recovers corrupt caches, isolates
lossy settings, preserves page dimensions, and rebuilds a deterministic merge rather
than appending duplicate pages after interrupted batches. The old batch-size option
is accepted; work is now per-page. CLI verification/strictness are always enabled.

Visual review identified two baseline limitations: Cairo inflated embedded JPEGs
and substituted fonts from SVG @font-face declarations, causing bad spacing and
clipped characters on text paths. The fork registers renamed, temporary copies of
source WOFF fonts through FontTools/Fontconfig and positions text using source
straight-path offsets and declared lengths. Original JPEG streams are restored only
when their Pillow-decoded RGB pixels exactly match the Cairo image resource.
Complex unsupported text paths fail rather than silently producing bad layout.

The verifier checks all page dimensions, page count, encryption, source PDF hashes,
rendered fingerprints for every page (content/order), extractable text, and nearly
uniform pages. First/middle/last and four seeded random pages are rendered for
visual inspection. Raster fingerprints check merge fidelity, not source typography;
visual review is necessary and caught the font issue during development.

X25's baseline source SVGs were individually parsed and hashed into a manifest to
avoid a redundant download. Every page PDF was regenerated by the final conversion
pipeline. No upstream partial-PDF output was reused. Sources and intermediate PDFs
are retained locally with --keep-cache, excluded from the public repository.

## Validation

Eleven offline synthetic tests pass, covering URL normalization/rejection, metadata
completeness/paywalls, transient retries/access denials, cache recovery, interruption
resume without duplicated pages, numeric order, dimensions, text extraction, missing
pages, original JPEG byte preservation, viewer cache busters, and path-end clipping.
Only Linux was executed. macOS/Windows setup guidance is unverified here.
